# 🚀 CRUD de Imagens com JavaScript, TailwindCSS e HTML

Projeto desenvolvido como parte da **📚 prova de suficiência** da disciplina de **Programação Web I (PW1)** na FURB.

## 🎯 Objetivo

Demonstrar domínio em desenvolvimento web **100% client-side**, utilizando apenas tecnologias do lado do navegador e uma API pública gratuita.

## 📸 Funcionalidades

- ➕ Inserir novas imagens com título, URL e ID do álbum
- 🔄 Alterar imagens existentes por ID
- ❌ Excluir imagens por ID
- 📄 Listar imagens com paginação (50 por página)
- 💾 Armazenamento local com **LocalStorage**
- 💻 Interface responsiva com **TailwindCSS**

## 🧰 Tecnologias utilizadas

- 🌐 **HTML5**
- ⚙️ **JavaScript (Vanilla)**
- 🎨 **TailwindCSS** (via CDN)
- 🔗 [**JSONPlaceholder API**](https://jsonplaceholder.typicode.com/photos)
- 📦 **LocalStorage**

## 🔌 API utilizada

Este CRUD consome dados da [JSONPlaceholder](https://jsonplaceholder.typicode.com/photos), uma API REST gratuita usada para testes, protótipos e estudos.
